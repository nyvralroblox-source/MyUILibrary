# Changelog

## 1.0.0 — 2026-09-24

- Initial public architecture: windows, tabs, sections, groupboxes.
- Components: Button, Toggle, Slider, Dropdown, Keybind, Colorpicker, Textbox, Paragraph, Label, Divider, Image.
- Services: drag, resize, notifications, window manager, tooltips.
- Dark / Light palettes with dynamic accent.
- JSON config for flags, theme, and window geometry.
- Central TweenService animation module.
